# 侧信道轨迹对齐方法对比综述

## 概述

在侧信道分析中，由于时钟抖动、采样相位漂移等因素，轨迹之间存在时间偏移。轨迹对齐是预处理的关键步骤，直接影响后续相关性分析或模板攻击的效果。

本文档对 Squirrel 框架提供的五种轨迹对齐方法进行综合对比：

| 方法 | 核心原理 | 适用波形 | 计算速度 | 抗噪声能力 |
|------|---------|---------|---------|-----------|
| **Peak** | 峰值检测 | 清晰单峰 | ★★★★★ | ★★☆☆☆ |
| **CrossCorr** | 互相关 | 高斯峰等平滑特征 | ★★★★☆ | ★★★☆☆ |
| **SAD** | 绝对差值和 | 有参考模板 | ★★★☆☆ | ★★★☆☆ |
| **DTW** | 动态时间规整 | 复杂波形、非线性变形 | ★★☆☆☆ | ★★★★☆ |
| **ZC** | 零交叉重采样 | 方波、陡峭边缘 | ★★★★☆ | ★★☆☆☆ |

---

## 1. Peak - 峰值检测对齐

### 原理

通过检测每条轨迹中的**峰值（最大值或最小值）**，然后将峰值与参考轨迹对齐。

**核心假设**：同一操作在所有轨迹中都会产生相同形状的峰值，只是位置可能偏移。

### 核心公式

**峰值检测：**
$$peak_{ref} = \arg\max_{i \in [start, end]} R_i$$
$$peak_{test} = \arg\max_{i \in [start, end]} T_i$$

**平移量计算：**
$$shift = peak_{ref} - peak_{test}$$

- $shift > 0$：测试轨迹峰值在参考**右侧**，需要**左移**
- $shift < 0$：测试轨迹峰值在参考**左侧**，需要**右移**

**零填充平移对齐：**
$$aligned[i] = \begin{cases}
0 & \text{若 } i - shift < 0 \\
T_{i-shift} & \text{若 } 0 \leq i - shift < N \\
0 & \text{若 } i - shift \geq N
\end{cases}$$

**测试波形**：单一尖锐正尖峰（amplitude=10, width~4 samples）

**对齐效果图**：

|------|------|

| 对齐后 MAE | **0.00 samples** |
| 对齐精度 (±5) | **100%** ✓ |

### 优缺点

|------|------|
| 简单快速 | 对噪声敏感 |
| 定位精确 | 多峰会混淆 |
| 计算量小 | 低幅度峰值难定位 |

## 2. CrossCorr - 互相关对齐

### 原理

通过计算测试轨迹与参考轨迹之间的**互相关（cross-correlation）**来检测时间偏移。

**核心思想**：当两条轨迹完全对齐时，它们的互相关峰值会出现在零偏移位置。通过找到互相关峰值的位置，可以计算出需要对齐的偏移量。

### 核心公式

**参考窗口提取：**
$$W = R_{start:end}$$

**互相关计算：**
$$C = \text{correlate}(T, W, mode='valid')$$

**平移量计算：**
$$shift = peak_{ref} - peak_{test}$$

**零填充平移对齐：**
$$aligned[i] = \begin{cases}
0 & \text{若 } i - shift < 0 \\
T_{i-shift} & \text{若 } 0 \leq i - shift < N \\
0 & \text{若 } i - shift \geq N
\end{cases}$$

**测试波形**：高斯峰（sigma=8, amplitude=10）

**对齐效果图**：

| 指标 | 数值 |
|------|------|
| 对齐前 MAE | 10.20 samples |
| 对齐后 MAE | **0.00 samples** |
| 对齐精度 (±5) | **100%** ✓ |
| 相关系数改善 | +0.3627 |

### 优缺点

| 优点 | 缺点 |
|------|------|
| 抗噪声能力强 | 需要合适窗口 |
| 对平滑信号效果好 | 平坦区域峰值不明显 |
| 整体对齐效果好 | 重复模式可能混淆 |

## 3. SAD - 绝对差值和对齐

### 原理

使用 **绝对差值和（Sum of Absolute Difference, SAD）** 找到将测试轨迹与参考轨迹对齐的最佳平移量。它在测试轨迹上滑动参考窗口，找到 SAD 最小的位置。

**核心思想**：当两条轨迹完全对齐时，它们对应位置的绝对差值最小。

### 核心公式

**SAD 计算：**
$$SAD(s) = \sum_{i=1}^{L} |t_{i+s} - w_i|$$

**最优平移：**
$$s_{opt} = \arg\min_{s \in [-max\_shift, max\_shift]} SAD(s)$$

**物理意义**：
- $s > 0$：测试轨迹偏右，需要左移 $|s|$ 个采样点
- $s < 0$：测试轨迹偏左，需要右移 $|s|$ 个采样点

### 测试波形与结果

**测试波形**：双尖峰（正负，±8 amplitude）

**对齐效果图**：

| 指标 | 数值 |
|------|------|
| 对齐前 MAE | 10.20 samples |
| 对齐后 MAE | **0.00 samples** |
| 对齐精度 (±5) | **100%** ✓ |
| 相关系数改善 | +0.7911 |

### 优缺点

| 优点 | 缺点 |
|------|------|
| 模板匹配精确 | 计算量中等 |
| 逐点优化 | 需要参考窗口 |
| 直观易懂 | max_shift限制搜索范围 |

## 4. DTW - 动态时间规整对齐

### 原理

使用 **快速动态时间规整（FastDTW）** 算法对齐轨迹。与简单的平移对齐不同，DTW 能找到两条时间序列之间点的最优对应关系，允许**非线性形变**。

**核心假设**：轨迹中的相同物理现象会以相似但可能变形的形式出现，DTW 通过动态规划找到最优匹配。

### 核心公式

**DTW 距离递推：**
$$D(i, j) = |r_i - t_j| + \min(D(i-1, j), D(i, j-1), D(i-1, j-1))$$

其中 $D(i, j)$ 表示 $R[1:i]$ 和 $T[1:j]$ 之间的最优 DTW 距离。

**FastDTW 优化**：
- 使用滑动窗口半径 $r$ 限制搜索范围
- 时间复杂度从 $O(N^2)$ 降低到 $O(r \cdot N)$

**对齐输出：**
$$aligned[i] = \frac{\sum_{(x,y) \in path, x=i} T[y]}{count_i}$$

### DTW 递推的三种走法

| 走法 | 含义 | 直观理解 |
|------|------|----------|
| $D(i-1, j)$ | 参考前进，测试停一下 | 测试轨迹这一段被"拉长" |
| $D(i, j-1)$ | 测试前进，参考停一下 | 参考轨迹这一段被"拉长" |
| $D(i-1, j-1)$ | 两边都前进 | 正常的一对一匹配 |

### 与平移对齐的本质区别

| 特性 | 平移对齐 | DTW |
|------|---------|-----|
| 形变类型 | 仅线性平移 | 非线性拉伸/压缩 |
| 匹配方式 | 整体对齐 | 局部最优匹配 |
| 计算复杂度 | $O(N)$ | $O(r \cdot N)$ |
| 适用场景 | 整体偏移 | 局部变形 |

### 测试波形与结果

**测试波形**：双尖峰（正负，±8 amplitude）

**对齐效果图**：

| 指标 | 数值 |
|------|------|
| 标准差降低 | **64.9%** |
| 方差降低 | 通过 ✓ |
| 适用波形 | 复杂波形、非线性变形 |

### 优缺点

| 优点 | 缺点 |
|------|------|
| 最灵活，适应性强 | 计算量大 |
| 支持非线性变形 | 参数调优复杂 |
| 不依赖单一特征 | 不适合简单平移 |

## 5. ZC - 零交叉重采样对齐

### 原理

通过检测**零交叉点**并将相邻交叉点之间的每段重采样到统一长度来对齐轨迹。

**核心思想**：方波或脉冲信号有清晰的上升沿/下降沿，这些边缘产生的零交叉点可以作为对齐的参考点。将相邻零交叉点之间的信号段标准化为相同长度，可以消除时间偏移的影响。

### 核心公式

**零交叉点检测：**
找到满足以下条件的索引 $i$：
$$(t_i - z) \geq 0 \text{ 且 } (t_{i-1} - z) < 0$$

即信号从负侧穿越到正侧的第一个采样点。

**平均区间长度：**
$$L_{avg} = \frac{\sum_{j=2}^{M} (ZC_j - ZC_{j-1})}{M-1}$$

其中 $M$ = 零交叉点数量，$ZC_j$ = 第 $j$ 个零交叉点索引。

**重采样：**
$$segment_{resampled} = \text{resample}(segment, L_{avg})$$

### 算法步骤

```
1. 检测ZC: 在参考轨迹中找出所有零交叉点
2. 计算区间长度: 计算相邻ZC间的平均距离
3. 重采样区间: 将ZC之间的每个区间重采样到 L_avg 长度
4. 拼接: 将所有重采样后的区间连接起来
```

### 测试波形与结果

**测试波形**：单脉冲方波（period=400, amplitude=5）

**对齐效果图**：

| 指标 | 数值 |
|------|------|
| 标准差降低 | **89.9%** ✓ |
| 相关性通过 | ✓ |
| 对齐精度（上升沿 ±5） | **100%** |

> **验证方法说明**：使用上升沿(rise-edge)检测验证对齐效果，而非峰值检测。因为方波脉冲的峰值区域是平坦的，峰值位置不确定。

### 优缺点

| 优点 | 缺点 |
|------|------|
| 有物理依据 | 对噪声敏感 |
| 可处理非线性偏移 | 性能取决于信号质量 |
| 无需参考窗口 | 输出长度可能与输入不同 |

### 曲线类型匹配表

| 方法 | 最适合的曲线类型 | 不适合的曲线类型 | 核心判断依据 |
|------|-----------------|-----------------|-------------|
| **Peak** 峰值检测 | 峰很清楚、重复周期明显、每个周期有稳定主峰的曲线 | 峰不明显、噪声峰很多、一个周期内有多个相似峰 | 找最大峰或关键峰的位置 |
| **CrossCorr** 互相关 | 整体形状相似、只有平移偏移的曲线 | 局部变形明显、周期内结构变化大、幅值漂移严重 | 找两段波形整体相似度最高的位置 |
| **SAD** 绝对差值和 | 有稳定模板、形状固定、幅值也比较一致的曲线 | 幅值变化大、局部拉伸压缩、噪声较强 | 找与模板差值最小的位置 |
| **DTW** 动态时间规整 | 形状相似但局部时间被拉伸/压缩的复杂波形 | 只需要简单平移对齐的大数据波形 | 允许局部非线性伸缩后匹配 |
| **ZC** 零交叉重采样 | 方波、脉冲、边缘陡峭、过零点稳定的曲线 | 平滑峰、没有明显过零点、噪声导致频繁过零 | 根据零交叉点或边缘位置重新对齐 |

## 核心公式汇总

| 方法 | 核心公式 | 优化目标 |
|------|---------|---------|
| **Peak** | $shift = \arg\max(R) - \arg\max(T)$ | 峰值位置对齐 |
| **CrossCorr** | $C = \text{correlate}(T, W)$, $shift = \arg\max(C_{ref}) - \arg\max(C)$ | 互相关最大化 |
| **SAD** | $s_{opt} = \arg\min_s \sum\|t_{i+s} - w_i\|$ | 绝对差值最小化 |
| **DTW** | $D(i,j) = \|r_i-t_j\| + \min(D(i-1,j), D(i,j-1), D(i-1,j-1))$ | 路径代价最小化 |
| **ZC** | $L_{avg} = \frac{\sum(ZC_j - ZC_{j-1})}{M-1}$ | 区间长度均匀化 |

## 局限性对比

| 方法 | 主要局限 |
|------|---------|
| **Peak** | 多峰干扰、噪声敏感、低幅度峰值难定位 |
| **CrossCorr** | 平坦区域峰值不明显、重复模式混淆 |
| **SAD** | 计算量中等、依赖参考窗口选择 |
| **DTW** | 计算量大、不适合简单线性平移 |
| **ZC** | 对噪声非常敏感、输出长度可能变化 |

## 总结建议

1. **首选 Peak**：对于干净、单一峰值的信号，Peak 方法简单快速且精度高

2. **高噪声环境**：选择 CrossCorr，互相关能有效抑制噪声影响

3. **复杂波形/非线性变形**：必须使用 DTW，其他方法无法处理局部拉伸压缩

4. **方波/脉冲信号**：ZC 方法利用边缘特征，是最佳选择

5. **有参考模板**：SAD 的逐点匹配最适合模板对齐场景

> **注意**：实际应用中，建议先用仿真数据测试各方法效果，选择最适合具体波形的对齐策略。
